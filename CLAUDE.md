# Instrucciones del proyecto para Claude

Leer y aplicar las instrucciones compartidas del proyecto:

@AGENTS.md

Para cualquier trabajo de interfaz, usar primero componentes de Nuxt UI y
configurarlos mediante sus props y API documentada. Si las props no bastan o
complican innecesariamente la solución, usar Tailwind mediante `class` y los
slots de estilo de `ui`, conforme a la API del componente. Consultar
[la skill de Nuxt UI](.agents/skills/nuxt-ui/SKILL.md) y los temas generados antes
de personalizar. Conservar los radios y tamaños definidos en `AGENTS.md`.

`AGENTS.md` es la fuente compartida de estas reglas; aplicar también sus
instrucciones de pruebas en navegador y las demás convenciones del proyecto.
